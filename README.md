# SkillBridge

A web and mobile-first skills development and opportunity matching system built with Next.js.

## Features
- Landing page
- Responsive mobile-first design
- Skills exploration
- Dashboard
- Opportunity browsing
- User profile page
- Match-ready foundation for future backend integration

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Project structure
- `app/` — pages and layouts
- `components/` — reusable UI components
- `lib/` — static data and logic helpers
